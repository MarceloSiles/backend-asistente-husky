PROBLEMAS PARA GENERAR PDF EN HUSKY

IMPORTANTE SEGÚN LA VERSIÓN DEL SISTEMA

Si el usuario usa Husky versión 35 o anterior:
- El sistema usa PDF Creator.
- Ante problemas para generar PDF, la primera solución recomendada es reinstalar y configurar PDF Creator.

Si el usuario usa Husky versión 36 o superior:
- Ya no se usa PDF Creator como solución principal.
- Se usa la impresora nativa de Windows llamada Microsoft Print to PDF.
- En ese caso hay que revisar que Windows 10 o superior tenga activa esa impresora y que esté disponible en el sistema.

RESPUESTA RECOMENDADA PARA EL ASISTENTE

Si el usuario no sabe qué versión tiene, primero preguntarle la versión de Husky. Si necesita una orientación rápida, indicarle:

1) Si tu Husky es versión 35 o anterior, revisamos PDF Creator.
2) Si tu Husky es versión 36 o superior, revisamos Microsoft Print to PDF.

CASO HUSKY VERSIÓN 35 O ANTERIOR - PDF CREATOR

Vamos paso a paso. No es grave, pero hay que reinstalar PDF Creator correctamente.

Link de descarga de PDF Creator:
https://www.mcsiles.com.ar/app/PDFCreator-1_2_3_setup.rar

Pasos:

1) Cerrá Husky.
2) En Windows, entrá a Panel de Control / Programas / Desinstalar un programa.
3) Si hay alguna versión de PDF Creator instalada, desinstalala.
4) Cuando pregunte si querés eliminar preferencias o ajustes del programa, respondé que sí.
5) Descargá PDF Creator desde el link indicado.
6) Abrí el archivo descargado.
7) Ejecutá PDFCreator-1_2_3_setup.exe.
8) Seguí los pasos normales de instalación.
9) Puede ocurrir que Windows pida instalar alguna característica adicional. Aceptá y esperá a que termine.
10) Al finalizar, abrí PDF Creator desde el ícono del escritorio.
11) Entrá en Impresora / Opciones.
12) Seleccioná Ajustes generales 2.
13) En Comprobar actualizaciones, elegí Nunca.
14) Guardá.
15) Entrá en AutoGuardado.
16) Activá AutoGuardado.
17) En formato de autoguardado, elegí PDF.
18) Guardá y cerrá todo.
19) Abrí Husky y probá generar el PDF nuevamente.

Importante: no debe quedar instalada otra versión de PDF Creator, porque puede generar conflictos.

CASO HUSKY VERSIÓN 36 O SUPERIOR - MICROSOFT PRINT TO PDF

En versión 36 o superior, Husky usa la impresora nativa de Windows Microsoft Print to PDF.

Pasos básicos:

1) Verificá que la PC tenga Windows 10 o superior.
2) Entrá a Configuración de Windows / Impresoras y escáneres.
3) Buscá Microsoft Print to PDF.
4) Si no aparece, tiene que activarla o reinstalarla un técnico en PC.
5) Si aparece, abrí Husky y revisá que el sistema esté usando esa impresora para generar PDF.

Si el usuario no sabe revisar impresoras de Windows, recomendar técnico en PC o soporte Husky.
