# Base de conocimiento Husky

Esta carpeta contiene documentos de conocimiento usados por el backend del asistente.

Formato recomendado por ahora:

- Archivos `.txt`
- Archivos `.md`

Los PDF deben convertirse a texto antes de subirlos a esta carpeta. Más adelante se puede agregar un proceso automático para extraer texto de PDF.

Sugerencia de organización:

- `manual-usuario.txt`
- `errores-frecuentes.txt`
- `facturacion-electronica.txt`
- `arca-wsfev1.txt`
- `procedimientos-soporte.txt`

El backend lee estos documentos, los divide en fragmentos y busca los más relacionados con la consulta del usuario.
